# Roadmap

Rough order. Nothing here is a promise with a date.

## Core

- Signing out in one tab signs out the others, through a
  `BroadcastChannel`.
- A small package for servers that checks EAuth access tokens against
  the published keys, for Node and the edge runtimes.

## Frameworks

- Vue without Nuxt.
- SolidJS and Angular, if applications on them ask.

## Not planned

Client secrets, the implicit flow, the password grant, and tokens in
`localStorage` by default. See the non-goals in the README.
