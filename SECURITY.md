# Security

If you find something in this repository that could let somebody take
over a session, read a token or sign in as somebody else, write to
security@elchi.dev. Say what you found, how to reproduce it and, if you
have one, what you would change. You get an answer within two working
days and a fix as fast as the finding needs, with credit if you want it.

Please do not open an issue for it.

Fixes are released for the latest 1.x version. The packages share one
version, so a fix is in the same version of every package.

EAuth itself (eauth.me, panel.elchi.dev) is covered by the same address;
the rules for testing the service are at
[docs.elchi.dev/security](https://docs.elchi.dev/security).
